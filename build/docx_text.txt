1  概述
1.1  文档目的
本文档定义 QYH-GD300 局部放电故障定位仪无线款的电脑端上位机软件设计方案，涵盖系统架构、无线通信协议、软件分层、数据模型、功能规格、界面规范、技术选型与开发计划。本文档是上位机组、嵌入式组、测试组三方协同开发的唯一基准，协议部分一经评审通过，双方须严格按帧格式并行开发。
1.2  适用范围
适用于 QYH-GD300 无线款配套上位机软件的设计、开发、测试与验收。
适用于接收端网关固件与上位机之间的接口约定。
适用于后续多型号局放监测产品的软件架构复用。

1.4  被测对象与测量原理边界
QYH-GD300 采用压电陶瓷传感器采集局部放电产生的声波信号，超限即报警。该原理决定了上位机软件的能力边界，必须在设计阶段明确，避免功能设计走偏。

结论：本上位机的产品定位是分布式声学监测网络软件，而非 PRPD 谱图分析仪。核心叙事为「多路声强监测 + 分级报警 + 强度对比定位」。

4.5.2  报警去抖（必做）
直接按单帧超阈值触发会导致误报刷屏，现场体验灾难。去抖策略：
连续 N 次（默认 3 次）采样超阈值才触发，N 可配置。
或滑动窗口内超限占比超过 P%（默认 60%）才触发。
去抖窗口内不升级、不重复报警，仅记录原始超限事件。
报警持续期间不重复弹窗，仅更新持续时长。
4.5.3  报警闭环
确认 / 消音 / 复位三类操作，全部留痕（操作人、时间、备注）。
阈值支持按节点单独设置，且可远程下发。
支持静音时段配置（如检修期间）。
报警记录持久化，支持按时间、节点、等级组合查询。
4.6  M5 强度对比定位
本模块是产品名「故障定位仪」在软件侧的落地，也是相对竞品的差异化功能。
布点示意图：支持导入现场平面图或柜体排列图，标注各节点实际位置。
强度可视化：以颜色深浅或柱高表示各节点实时 / 峰值强度。
最强路推定：自动标出强度最高的节点及其相邻节点，给出疑似放电源区域提示。
历史对比：支持回放某一时刻的强度分布快照，观察放电源迁移趋势。
算法说明：基于 AE 信号随传播距离衰减的特性，在同类传感器、同等增益条件下，接收强度最高的测点距放电源最近。当前版本采用强度排序法给出区域推定，后续可升级为多点 TDOA 时差定位。
4.7  M6 历史查询与报表
条件查询：时间区间、节点、报警等级、状态组合过滤。
回放：选定时间段重放曲线演变，支持倍速。
导出：CSV / Excel 原始数据，PDF 巡检报告。
统计：各节点超限次数、平均强度、最大强度、在线率。
4.8  M7 系统设置
通信参数：串口号、波特率、TCP 地址与端口。
网络参数：轮询周期、超时、重试次数、补传策略。
报警参数：各级阈值、去抖次数、声音开关、静音时段。
工程文件：节点配置、布点图、布局偏好的保存与加载。
用户权限：操作员 / 管理员两级，参数下发与删除操作需管理员权限。

6  界面设计
6.1  设计原则
信息分层：核心指标（报警状态、最大强度）置于首屏，历史与配置收进次级页面。
状态色语义唯一：颜色只由 alarm_level 驱动，不承载其他含义。
数值可读性：实时读数用等宽字体，固定小数位，单位以较小字号次要色紧跟。
容错显示：数值无效时显示「--」，禁止出现 NaN / null / 0 占位。
深色工业主题：适配变电站、配电房等低照度现场环境，降低长时间值守疲劳。

7.2  选型依据
采用「Web 前端 + 极简本地服务」的三条核心理由：
声明式 UI 更适合 AI 全量开发。Vue 模板与 HTML 同构，树形结构一目了然，相比命令式的 PySide6 布局代码（addWidget / setLayout 序列）大幅降低漏调用风险。
具备截屏验证闭环。AI 写完代码可直接在浏览器打开、截图、把图与问题一并反馈，形成紧凑的生成—验证循环。这是桌面 GUI 不具备的能力。
一套前端同时满足两种交付形态。本地单机时浏览器访问 localhost，未来扩展为远程监测时只需部署到服务器，无需重写。
关于备选方案：若客户现场明确要求单一 exe 桌面程序且禁止浏览器环境，则改用 C# WPF + XAML + ScottPlot，协议层与数据层可原样复用。
