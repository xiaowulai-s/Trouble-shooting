# LoRa 主机–从机通信协议说明书

- 版本：v1.0（基于需求草稿整理，并修正命令码冲突）
- 日期：2026-10-10
- 适用范围：1 台主机 + 最多 40 台从机（地址 `0x0001~0x0028`）的 LoRa 半双工通信
- 说明：第 6 条「电池供电（信标同步 + 时隙 + 休眠）」暂不实现，相关命令仅作**预留**

> 约定：标 **【原稿】** 的内容来自需求草稿；标 **【新增定义·待确认】** 的是本说明书为可用性补齐的定义，
> 需与需求方确认后固化；标 **【待定义】** 的是原稿明确保留、尚未给出的内容。

---

## 1. 概述

| 项 | 内容 |
| --- | --- |
| 拓扑 | 1 主机 + ≤40 从机 |
| 介质 | LoRa，半双工、低速、随机接入碰撞较严重 |
| 通信策略 | **主机轮询问答为主**，从机事件/告警**主动上报为辅** |
| 实现范围 | 通信模式 1~5；第 6 条（电池供电）暂不做 |
| 字节序 | 多字节字段**小端**（低字节在前） |

## 2. 角色与地址

| 角色 | 地址 |
| --- | --- |
| 主机 | `0x0000` |
| 从机 | `0x0001 ~ 0x0028`（共 40） |
| 广播 | `0xFFFF` |

## 3. 帧格式

所有帧统一采用如下通用帧（含从机主动上报）：

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 帧头 FrameHeader | 2B | `0xAA55` |
| 目标地址 DstAddr | 2B | 帧的接收方地址（主机 `0x0000` / 从机地址 / 广播 `0xFFFF`） |
| 源地址 SrcAddr | 2B | 帧的发送方地址 |
| 序列号 Seq | 1B | `0~255` 循环 |
| 命令码 Cmd | 1B | 见第 4 章 |
| 长度 Len | 1B | 载荷字节数（`0~255`） |
| 载荷 Payload | N B | 命令相关，见第 5 章 |
| CRC16 | 2B | MODBUS CRC16，多项式 `0xA001` |

- 固定开销 `11B`，整帧 = `11 + Len` 字节；Len 上限 255 → 整帧上限 266B。
- **【新增定义·待确认】帧头线序**：先发 `0xAA`，再发 `0x55`。
- **【新增定义·待确认】CRC 计算范围**：自 `目标地址` 起至 `载荷` 末字节止（**不含帧头**），
  初值 `0xFFFF`，多项式 `0xA001`（反射式）；CRC 字段本身**小端**（低字节在前）。
- 从机主动上报（告警/事件）同样使用本通用帧，`目标地址` = 主机 `0x0000`，`源地址` = 该从机地址。

## 4. 命令码

**划分规则**

| 区间 | 方向 | 用途 |
| --- | --- | --- |
| `0x01~0x0F` | 主→从 | 主机请求 |
| `0x81~0x8F` | 从→主 | 对应请求的应答（规则：`应答 = 请求 \| 0x80`） |
| `0xA0~0xAF` | 从→主 | 从机主动上报 |
| `0xB0~0xBF` | 主→从 | 主机对主动上报的确认（与上报一一对应） |

| 命令码 | 名称 | 方向 | 应答/确认 | 备注 |

## 5. 载荷定义

> 原稿仅给出「读数据/写参数/控制/告警」的流程示意，具体载荷多为保留，逐条标注。

### 5.1 读数据

- 请求 `0x01`：`Len = 1`，`Payload = 0xAA`（固定，无参）
- 应答 `0x81`：`Len = N`，`Payload = 数据` —— **【待定义】**（数据字段布局）

### 5.2 读参数

- 请求 `0x02`：`Payload = 参数标识` —— **【待定义】**（参数 ID 编码表）
- 应答 `0x82`：`Payload = 参数值` —— **【待定义】**

### 5.3 写参数

- 请求 `0x03`：`Payload = 参数标识 + 参数值` —— **【待定义】**
- 应答 `0x83`：`Payload = 结果` —— **【待定义】**（成功/失败码）

### 5.4 控制命令

- 请求 `0x04`：`Payload = 控制码 + [控制参数]` —— **【待定义】**（控制码表）
- 应答 `0x84`：`Payload = 结果` —— **【待定义】**
- 从机对同一 `Seq` 的控制命令**去重**，防止重复执行（见 6.3）

### 5.5 心跳/在线检测

- 请求 `0x05`：`Payload` 可空
- 应答 `0x85`：`Payload` 可空（或携带从机状态）—— **【待定义】**

### 5.6 时间同步/时隙配置（预留）

- 请求 `0x06` / 应答 `0x86`：**暂不实现**，载荷 **【待定义】**

### 5.7 广播

- 请求 `0x07`：`Payload = 广播内容` —— **【待定义】**
- 应答：默认**无应答**；如需确认，从机以 `0x87` 在指定时隙回应（分槽确认，见 6.5）

### 5.8 告警主动上报

- `0xA0`：`Payload = 告警码 + [告警数据]` —— **【待定义】**（告警码表）
- 流程：退避后上报 → 等 `0xB0` 确认 → 未收到则重发（≤3 次）

### 5.9 事件主动上报

- `0xA1`：`Payload = 事件码 + [事件数据]` —— **【待定义】**（事件码表）
- 流程：同上，等 `0xB1` 确认

### 5.10 确认

- `0xB0`（告警确认）/ `0xB1`（事件确认）：`Len = 1`，`Payload = 0xAA`（固定）
- 确认帧的 `Seq` 与被确认的上报帧 `Seq` 一致，用于从机匹配

## 6. 交互时序

### 6.1 在线检测（周期轮询）

```
主机 → 从机N :  帧头+Dst(从机N)+Src(0x0000)+Seq+Cmd 0x05+Len(0)+CRC
从机N → 主机 :  帧头+Dst(0x0000)+Src(从机N)+Seq+Cmd 0x85+Len(0)+CRC
```
主机的从机表按地址 `0x0001~0x0028` 轮询，超时未应答标记「离线」。

### 6.2 写参数

```
主机 → 从机N :  ... + Cmd 0x03 + Len + [参数标识+参数值] + CRC
从机N → 主机 :  ... + Cmd 0x83 + Len + [结果] + CRC
```

### 6.3 控制命令（序列号去重）

```
主机 → 从机N :  ... + Cmd 0x04 + Len + [控制码...] + CRC
从机N → 主机 :  ... + Cmd 0x84 + Len + [结果] + CRC
```
- 从机维护最近收到控制命令的 `Seq` 记录，**重复 `Seq` 直接丢弃、不重复执行**，但仍回 `0x84`。
- `Seq` 为 1B、256 回绕，去重窗口大小 **【待定义】**。

### 6.4 从机告警主动上报

```
从机N :  随机退避 0~2s（可配）后上报
        帧头+Dst(0x0000)+Src(从机N)+Seq+Cmd 0xA0+Len+[告警码...]+CRC
主机  :  帧头+Dst(从机N)+Src(0x0000)+Seq+Cmd 0xB0+Len(1)+0xAA+CRC
从机N :  未收到确认则重发，最多 3 次
```
- 主机收到告警后，将从机表中该地址标记为「告警态」；**经过一段时间后**再轮询读取其数据。
  「一段时间」**【待定义】**（建议值见第 8 章）。

### 6.5 广播

```
主机 → 广播 :  ... + Dst(0xFFFF) + Cmd 0x07 + Len + [内容] + CRC
```
默认无应答；若需分槽确认，从机在各自时隙回 `0x87`（分槽规则 **【待定义】**）。

## 7. 主机调度与从机状态机（建议）

- **主机**：维护从机表；轮询状态（在线/离线/告警）；普通轮询与「告警优先读取」两条队列。
- **从机**：`运行` → 事件/告警触发 `上报中(退避/重发)` → 收到确认回到 `运行`。
- 半双工下主机需在上报高发期**留出侦听窗口**，避免与轮询互相冲突（策略 **【待定义】**）。

## 8. 定时/超时/重试（建议值 · 待确认）

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| 轮询周期（单机） | 待定 | 需按 40 台与 LoRa 速率估算一圈时长 |
| 单次应答超时 | 待定 | 主机发出请求后等待应答的时间 |
| 主机重试次数 | 待定 | 轮询/写参数/控制失败重试上限 |
| 从机退避 | `0~2s`（可配） | 原稿明确 |
| 从机重发上限 | `3` 次 | 原稿明确 |
| 告警读取延迟 | 待定 | 主机「标记告警态后轮询」的等待时长 |
| 去重窗口 | 待定 | 控制命令 `Seq` 去重保留条数 |

## 10. 待确认项

1. 各命令载荷结构：读数据/读参数/写参数/控制/心跳/广播（第 5 章 **【待定义】**）。
2. 编码表：参数标识、控制码、告警码、事件码、从机状态码。
3. 定时参数：轮询周期、应答超时、重试次数、告警读取延迟、去重窗口（第 8 章）。
4. 广播：是否需要分槽确认；分槽规则。
5. 帧头线序与 CRC 范围/字节序（第 3 章【新增定义·待确认】）。
6. 半双工冲突处理：主机侦听窗口 / 上报优先级策略。
7. 从机地址范围与并发规模是否固定为 40（`0x0028`）。
